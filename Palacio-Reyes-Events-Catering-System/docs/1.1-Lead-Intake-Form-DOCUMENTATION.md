# Lead Intake Form - Documentation

## Overview

The **Lead Intake Form** is the first touchpoint in the Palacio Reyes Events & Catering sales process. It captures comprehensive event details uniformly, enabling your team to quickly qualify leads, assess risks, and provide accurate quotes.

### Purpose

- **Capture every inquiry uniformly** so no critical details are missed
- **Enable rapid lead qualification** through structured data collection
- **Reduce back-and-forth** by gathering all necessary information upfront
- **Feed the Event Master Sheet** with consistent, validated data
- **Identify risk factors early** to protect margins and reduce disputes

---

## Features

### ✨ Interactive Form Capabilities

1. **Auto-Generated Event ID** - Creates unique identifiers (format: `PR-YYYYMMDD-XXXXXX`)
2. **Auto-Save Functionality** - Prevents data loss with automatic draft saving every 30 seconds
3. **Client-Side Validation** - Ensures data quality before submission
4. **Phone Number Formatting** - Automatically formats phone numbers as `(555) 555-5555`
5. **Multiple Export Options**:
   - Submit to database/backend
   - Export as JSON for integration
   - Print as PDF for manual processing
   - Save as draft for later completion

### 📋 Data Collection Sections

#### 1. Event Basics
- Preferred date, time, and duration
- Date/time flexibility assessment
- Venue information and type
- Load-in/access requirements
- On-site contact details

#### 2. Headcount & Budget
- Minimum, target, and maximum guest counts
- Headcount flexibility assessment
- Per-guest and total budget ranges
- Budget flexibility indicators

#### 3. Event Type & Service Style
- Event category (corporate, non-profit, private, etc.)
- Event description and purpose
- Preferred service styles (buffet, plated, stations, etc.)

#### 4. Contact & Billing Information
- Primary contact details
- Decision maker identification
- Billing entity information
- Corporate/fiscal sponsor tracking

#### 5. Priorities & Requirements
- Top two non-negotiable priorities
- Dietary restrictions and allergies
- Allergy coordinator designation
- Special requests and considerations

#### 6. Internal Risk Assessment (Staff Only)
- Payment risk rating (1-3 scale)
- Venue complexity notes
- Risk flags and concerns

#### 7. Marketing Attribution
- Referral source tracking
- Marketing channel identification
- ROI measurement data

## How to Use

### For Sales Team

1. **Receive Inquiry** - Client submits form via website, email link, or in-person meeting
2. **Review Submission** - Check auto-generated Event ID and review all fields
3. **Assess Risk** - Complete internal assessment section if not already done
4. **Qualify Lead** - Use data to complete Qualification Checklist (1.2)
5. **Take Action**:
   - Send auto-response acknowledgment
   - Schedule discovery call if needed
   - Prepare quote/proposal if qualified

### For Clients

1. **Access Form** - Via website, email link, or PDF
2. **Complete All Required Fields** - Marked with red asterisks (*)
3. **Provide Context** - Fill out description and special request fields thoroughly
4. **Save Draft** - Use "Save Draft" button if you need to step away
5. **Submit** - Click "Submit Lead Intake Form" when complete
6. **Receive Confirmation** - Auto-response email with Event ID and next steps

## Technical Integration

### Connecting to Backend Systems

The form is designed to work standalone or integrate with your backend. Here are integration options:

#### Option 1: JavaScript Backend Integration

Modify the form submission handler in the `<script>` section:

```javascript
form.addEventListener('submit', async function(e) {
    e.preventDefault();

    // Collect form data
    const formData = collectFormData();

    // Send to your backend API
    try {
        const response = await fetch('https://your-api.com/leads', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
            },
            body: JSON.stringify(formData)
        });

        if (response.ok) {
            // Show success message
            showSuccessMessage();
            // Send auto-response email (server-side)
        }
    } catch (error) {
        console.error('Submission error:', error);
        alert('Error submitting form. Please try again.');
    }
});
```

#### Option 2: Google Sheets Integration

Use Google Apps Script to capture form submissions:

1. Create a Google Sheet with columns matching form fields
2. Deploy a Google Apps Script web app endpoint
3. Update the form to POST to the script URL
4. Script appends row to sheet and sends auto-response

**Sample Apps Script:**
```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.openById('YOUR_SHEET_ID').getActiveSheet();
  const data = JSON.parse(e.postData.contents);

  sheet.appendRow([
    data.eventID,
    data.submissionDate,
    data.contactName,
    data.contactEmail,
    // ... all other fields
  ]);

  // Send auto-response email
  MailApp.sendEmail({
    to: data.contactEmail,
    subject: 'Palacio Reyes - Event Inquiry Received',
    body: 'Thank you for your inquiry...'
  });

  return ContentService.createTextOutput(JSON.stringify({success: true}));
}
```

#### Option 3: Email Submission

Configure the form to send submissions via email:

```javascript
// Add email submission (requires server-side processing)
const mailtoLink = `mailto:events@palacioreyesevents.com?subject=Lead%20Intake%20-%20${eventID}&body=${encodeURIComponent(JSON.stringify(formData, null, 2))}`;
```

#### Option 4: CSV Export for Manual Entry

Use the built-in JSON export feature:
1. Client completes form
2. Click "Export as JSON"
3. Sales team imports JSON into Event Master Sheet
4. Use provided CSV template for batch imports

## Validation Rules

### Required Fields
- Event Date
- Venue
- Minimum & Target Headcount
- Event Type
- Contact Name, Email, Phone
- Top Two Priorities

### Field-Specific Validation
- **Email**: Must be valid email format
- **Phone**: Accepts digits, spaces, dashes, parentheses
- **Event ID**: Auto-generated, format `PR-YYYYMMDD-XXXXXX`
- **Numbers**: Min/max constraints on budget, headcount, duration
- **Dates**: Must be valid date format

### Business Logic Validation

Add custom validation in the submit handler:

```javascript
// Example: Ensure max headcount >= target
if (parseInt(formData.headcountMax) < parseInt(formData.headcountTarget)) {
    alert('Maximum headcount must be greater than or equal to target headcount.');
    return false;
}

// Example: Warn if budget seems low
const perGuestBudget = parseFloat(formData.budgetPerGuest);
if (perGuestBudget < 25) {
    if (!confirm('Budget per guest is below our typical minimum. Continue anyway?')) {
        return false;
    }
}
```

## Troubleshooting

### Form Not Saving Draft
- **Check Browser Settings**: Ensure localStorage is enabled
- **Clear Old Drafts**: Use browser dev tools → Application → Local Storage → Clear
- **Incognito Mode**: Note that drafts won't persist in incognito/private browsing

### Event ID Not Generating
- **JavaScript Disabled**: Enable JavaScript in browser
- **Check Console**: Open browser dev tools → Console for errors
- **Manual Assignment**: If needed, manually create Event ID following format

### Form Won't Submit
- **Required Fields**: Ensure all fields marked with * are completed
- **Network Connection**: Check internet connection if submitting to server
- **Browser Compatibility**: Use modern browser (Chrome, Firefox, Safari, Edge)

### Phone Number Not Formatting
- **JavaScript Required**: Phone formatting requires JavaScript
- **Manual Entry**: Users can still enter phone numbers manually
- **Validation**: Backend should accept various phone formats
