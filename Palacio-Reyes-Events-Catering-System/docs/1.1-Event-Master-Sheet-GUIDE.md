# Event Master Sheet - Setup & Usage Guide

## Overview

The **Event Master Sheet** is your central tracking system for all event leads and bookings. Every lead captured through the Lead Intake Form (1.1) creates a new row in this sheet, providing a single source of truth for your sales pipeline.

---

## Quick Start

### Option 1: Google Sheets (Recommended)

1. **Import CSV Template**
   - Open Google Sheets
   - File → Import → Upload the `1.1-Event-Master-Sheet-Template.csv` file
   - Choose "Replace spreadsheet" or "Insert new sheet"

2. **Format the Sheet**
   - Freeze top row: View → Freeze → 1 row
   - Apply filter: Data → Create a filter
   - Add conditional formatting (see below)

3. **Set Up Auto-Population** (Optional)
   - Connect to Lead Intake Form via Google Apps Script
   - Or manually import JSON exports from form submissions

### Option 2: Microsoft Excel

1. **Import CSV**
   - Open Excel
   - Data → From Text/CSV → Select template file
   - Load as table

2. **Format as Table**
   - Select all data → Home → Format as Table
   - Enable filters
   - Freeze top row: View → Freeze Panes → Freeze Top Row

### Option 3: Airtable / Notion / Database

1. **Create Base/Database**
   - Use CSV to populate initial fields
   - Map field types (date, number, select, etc.)
   - Create views for different statuses

2. **Set Up Automations**
   - Auto-assign leads based on event type
   - Send notifications when new leads arrive
   - Trigger follow-up reminders

## Recommended Views & Filters

### View 1: Active Pipeline
**Purpose**: Focus on leads currently being worked

**Filter**:
- Status = Submitted, Qualified, or Quoted
- Event Date >= Today

**Sort**:
- Event Date (ascending)
- Submission Date (ascending)

### View 2: This Month's Events
**Purpose**: See all events happening this month

**Filter**:
- Event Date: Current month
- Status != Declined or Cancelled

**Sort**:
- Event Date (ascending)

### View 3: Needs Follow-Up
**Purpose**: Identify stale leads needing attention

**Filter**:
- Status = Submitted or Quoted
- Last Modified: More than 3 days ago

**Highlight**: Red background

### View 4: High-Value Opportunities
**Purpose**: Prioritize large or strategic events

**Filter**:
- Headcount Target >= 100 OR Budget Per Guest >= $75
- Status = Submitted or Qualified

**Sort**:
- Budget Per Guest (descending)

### View 5: By Sales Team Member
**Purpose**: Individual team member workload

**Group By**: Assigned To

**Filter**: Status != Declined or Completed

## Formulas & Calculations

### Google Sheets Formulas

**Estimated Revenue** (create new column):
```
=IF(AND(NOT(ISBLANK(O2)), NOT(ISBLANK(Q2))), O2 * Q2, "")
```
*Where O2 = Headcount Target, Q2 = Budget Per Guest*

**Days Until Event**:
```
=IF(NOT(ISBLANK(I2)), I2 - TODAY(), "")
```
*Where I2 = Event Date*

**Follow-Up Urgency** (days since last modified):
```
=IF(AND(NOT(ISBLANK(AM2)), OR(C2="Submitted", C2="Quoted")), TODAY() - AM2, "")
```
*Where AM2 = Last Modified, C2 = Status*

**Risk Alert** (flag high-risk overdue follows-ups):
```
=IF(AND(X2>=2, TODAY()-AM2>5, OR(C2="Submitted", C2="Quoted")), "⚠️ URGENT", "")
```
*Where X2 = Risk Rating, AM2 = Last Modified, C2 = Status*

### Excel Formulas

Same logic as Google Sheets; formulas are compatible.

## Data Validation Rules

### Status Field
- Type: List from range
- Options: Draft, Submitted, Qualified, Quoted, Contracted, Declined, Cancelled, Completed
- Show dropdown: Yes

### Risk Rating Field
- Type: Number
- Minimum: 1
- Maximum: 3
- Show validation help: "1=Low, 2=Medium, 3=High"

- Type: Date
- Minimum: Today's date
- Warning: "Event date is in the past - is this correct?"

### Budget Per Guest Field
- Type: Number
- Minimum: 0
- Format: Currency ($)

## Automation Ideas

### Google Sheets + Apps Script

**Auto-Assign Leads by Event Type**:
```javascript
function autoAssignLeads() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Event Master');
  const data = sheet.getDataRange().getValues();

  for (let i = 1; i < data.length; i++) {
    const eventType = data[i][10]; // Column K - Event Type
    const assignedTo = data[i][3];  // Column D - Assigned To

    if (!assignedTo && eventType) {
      let salesPerson = '';
      switch(eventType) {
        case 'Wedding':
          salesPerson = 'Lisa Patel';
          break;
        case 'Corporate':
        case 'Brand Activation':
          salesPerson = 'Maria Santos';
          break;
        case 'Non-Profit':
          salesPerson = 'James Cooper';
          break;
        default:
          salesPerson = 'Sales Team';
      }
      sheet.getRange(i + 1, 4).setValue(salesPerson); // Update Assigned To
    }
  }
}
```

**Send Slack/Email Notification for New Leads**:
```javascript
function onNewLead(e) {
  const row = e.range.getRow();
  const sheet = e.source.getActiveSheet();

  const eventID = sheet.getRange(row, 1).getValue();
  const contactName = sheet.getRange(row, 5).getValue();
  const eventType = sheet.getRange(row, 11).getValue();
  const assignedTo = sheet.getRange(row, 4).getValue();

  const message = `🎉 New ${eventType} lead!\n` +
                  `Event ID: ${eventID}\n` +
                  `Contact: ${contactName}\n` +
                  `Assigned to: ${assignedTo}`;

  // Send to Slack webhook
  UrlFetchApp.fetch('YOUR_SLACK_WEBHOOK_URL', {
    method: 'post',
    payload: JSON.stringify({ text: message })
  });

  // Or send email
  MailApp.sendEmail({
    to: 'sales@palacioreyesevents.com',
    subject: `New Lead: ${eventID}`,
    body: message
  });
}
```

**Auto-Update Last Modified Timestamp**:
```javascript
function onEdit(e) {
  const sheet = e.source.getActiveSheet();
  const row = e.range.getRow();

  if (row > 1) { // Skip header row
    const lastModifiedCol = 40; // Column AN - Last Modified
    sheet.getRange(row, lastModifiedCol).setValue(new Date());
  }
}
```

## Integration with Lead Intake Form

### Manual Process
1. Client submits Lead Intake Form
2. Form exports to JSON
3. Sales team imports JSON data into new row
4. Update Status to "Submitted"
5. Assign to appropriate team member

### Automated Process (Google Sheets)
1. Lead Intake Form submits via Google Apps Script endpoint
2. Script automatically appends row to Event Master Sheet
3. Triggers auto-assign function
4. Sends notification to assigned team member
5. Sends auto-response email to client

## Reporting & Analytics

### Key Metrics to Track

**Lead Volume**:
- Total leads per month
- Leads by source
- Leads by event type

**Conversion Rates**:
- Submitted → Qualified: Target >60%
- Qualified → Quoted: Target >80%
- Quoted → Contracted: Target >30%

**Response Time**:
- Average hours from Submission to first contact
- Target: <24 hours

**Revenue Pipeline**:
- Total estimated revenue (Qualified + Quoted + Contracted)
- Average deal size by event type
- Monthly revenue forecast

### Sample Pivot Table (Google Sheets)

**Rows**: Event Type
**Columns**: Status
**Values**: Count of Event ID

## Exporting & Archiving

### When to Archive
- Events with Status = "Completed" and >30 days past event date
- Events with Status = "Declined" and >90 days past submission

### How to Archive (Google Sheets)
1. Create "Event History" sheet
2. Copy completed/old events to History sheet
3. Delete from active Event Master Sheet
4. Maintain Event ID for reference

### Backup Schedule
- **Daily**: Automatic Google Sheets version history
- **Weekly**: Download CSV backup to secure location
- **Monthly**: Export full sheet to Google Drive folder

## Troubleshooting

**Problem**: Duplicate Event IDs
**Solution**: Event IDs should be unique. Check form generation logic. Manually add suffix if duplicate found (e.g., PR-20250315-A7B9C2-B)

**Problem**: Formulas breaking when rows deleted
**Solution**: Use structured references (Tables in Excel) or named ranges in Google Sheets

**Problem**: Sheet becoming slow with large data
**Solution**: Archive old events; consider database solution (Airtable, Notion) for >1,000 records

**Problem**: Team members not getting notifications
**Solution**: Verify automation scripts are enabled; check email/Slack webhook URLs
